# MoreMobility (UNOFFICIAL) — NeoForge 1.21.1

An unofficial NeoForge port of [MoreMobility by BlueShapes](https://github.com/BlueShapes/MoreMobility), an addon for [Automobility](https://modrinth.com/mod/automobility). This project is independently maintained and is not affiliated with or endorsed by the original authors.

## Features

- Netherite engine.
- Silver and race shopping cart automobile frames.
- Advanced Crop Harvester front attachment with a wider harvesting area.
- Configurable off-road speed reduction; off-road wheels receive a smaller reduction.
- Auto Mechanic Table recipes visible in EMI and JEI when either recipe viewer is installed.

## Requirements

- Minecraft 1.21.1.
- NeoForge 21.1 or newer.
- Automobility NeoForge for Minecraft 1.21.1.

EMI and JEI integrations are optional and activate when the respective mod is installed.

## Build

Use Java 21 and the included Gradle wrapper:

```text
gradlew build
```

The built mod JAR is written to `build/libs/`.
